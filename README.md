# Dreamdrive
Retro gaming accessories produced by Dreamcraft Industries. Dreamdrive is coming to disc based systems called Dreamdisc! Dreamcast is the first console to get this treatment. Work is in progress to finalize the hardware and software for a first producion run. Stay tuned!

## [Discord](https://discord.gg/sHbhx2qJuK)
Join the discussion and get the latest on Dreamdrive status. Chat with other hackers. Have ideas on a new Dreamdrive product? Come and let me know. 

# Dreamdumper64
New Dreamdumper64 hardware files have been checked in! Navigate to `N64/hw/cart_tester/pc64` for the latest kicad project files.

# Projects
Current project status

| Project | Platform | Purpose  | Status | Notes |
| ------------- | ------------- | ------------- | ------------- | ------------- |
| Dreamdumper64 | N64 | Backup your cartridges | Finished | Completed units are available [here](https://dreamcraftindustries.com/products/dreamdumper64-assembled)!|
| Dreamdisc | Dreamcast | Dreamdive ODE For Dreamcast | Prototype/v3 | Repo files wont boot yet but the design has been verified and will be available soon |
| Dreamdrive Advance | GBA | Developer rom cart | Prototype/v2 | Waiting for new board designs with support for faster psram. Current PSRAM on the qspi bus isn't fast enough to service the cart |
| Super Dreamdrive | SNES | Developer rom cart | Prototype/v1 | Drafted prototype hardware and software. No idea if this is working |
